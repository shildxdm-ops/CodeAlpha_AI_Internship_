# 🌐 AI Language Translator

A simple AI-powered language translation tool built using Python and Streamlit.

## 📌 Features

- Translate text between multiple languages
- Simple and user-friendly interface
- Supports languages like English, Hindi, French, German, Spanish, Japanese, etc.
- Real-time translation using Google Translator
- Displays translated text clearly
- Error handling for failed translations

## 🛠️ Technologies Used

- Python
- Streamlit
- Deep Translator
- Google Translate
